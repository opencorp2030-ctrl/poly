Boilerplate

Poly is a free, open-source, cross-platform CLI package manager: one command routes to pip, npm, Homebrew, cargo, or its own checksum-verified binary downloads, whichever actually has the package. It works alongside existing tools rather than replacing them, and connects to AI assistants like Claude via its own MCP server.

Quick facts

  • License: MIT, open source on GitHub
  • Platforms: macOS, Linux, Windows
  • Pricing: free, with a one-time €0.99 Pro unlock (concurrent installs, auto-upgrade)
  • Built with: Go (CLI), Supabase (backend), plain HTML/CSS/JS (site)
