Get poly

You're already running Poly Desktop, but the CLI is a separate install (the Packages tab uses it). Native installers for macOS and Windows; both unsigned for now, so your OS will warn on first run.

git clone https://github.com/opencorp2030-ctrl/poly.git cd poly go build -o poly . ./poly version

Cross-compiling only needs GOOS/GOARCH, e.g. GOOS=windows GOARCH=amd64 go build -o poly.exe .

How a name resolves to an adapter

Without a prefix, poly install name tries each adapter's search in this order and installs through the first hit:

tap → brew → pip → npm → cargo → go
CommandResolves to
poly install ripgrepfirst match: tap → brew → pip → npm → cargo → go
poly install tap:ripgrepforced binary download from the tap formula
poly install pip:requestsforced pip install requests
poly install npm:lodashforced npm install -g lodash

Commands

CommandDoes
poly install [[adapter:]name[@version] ...]Install one or more packages, auto-routed or forced. No args installs from poly.json.
poly remove nameUninstall, via whichever adapter installed it.
poly listShow everything poly has installed.
poly search [adapter:]nameCheck existence and latest version.
poly init [--force]Write poly.json from what's currently installed.
poly upgradeUpdate every installed package to its latest version.
poly self-updateUpdate poly itself to the latest release.
poly login / logoutSign in/out. Credentials live in ~/.poly/credentials.json.
poly send name version pathPublish to the community registry.
poly doctorCheck for common setup problems.

State lives in ~/.poly/manifest.json. Tap binaries land in ~/.poly/bin — make sure it's on your PATH.

Reproducible installs: poly.json

poly init writes poly.json listing every installed package, pinned to its exact version:

{ "packages": [ "tap:ripgrep@15.1.0", "npm:eslint@9.2.0", "pip:requests@2.31.0" ] }

Commit it. Anyone reproduces the same environment with a plain poly install, no arguments needed.

Writing a tap formula

Drop a YAML file into ~/.poly/taps/<name>.yaml, overriding any built-in formula of the same name:

name: ripgrep version: "15.1.0" binary: rg artifacts: windows_amd64: { url: "...", sha256: "..." } darwin_arm64: { url: "...", sha256: "..." } linux_amd64: { url: "...", sha256: "..." }

Built-in formulas today, all free: ripgrep, fd, jq.

Publishing your own package

poly send name version path uploads a file or directory to the community registry under your account.

poly login poly send hello-world 1.0.0 ./dist/hello-world poly install community:hello-world

No malware scanning — only install community packages you trust. Names are first-come-first-served.
